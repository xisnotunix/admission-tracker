# Дорожная карта: промпты для доработок

Каждый промпт самодостаточный: его можно отдать отдельной сессии Claude Code в этом репозитории.
Порядок выполнения — от простых к сложным: 1 → 2 → 4 → 6 → 7 → 9 → 3 → 5 → 8. Пункт 10 (больше программ) выполнен первым по запросу.

Общий контекст для всех промптов:
> Репозиторий `admission-tracker` — трекер поступления для школьника из Кыргызстана (бакалавриат, Computer Science или Social Studies).
> Статический фронтенд без сборки (`index.html`, `assets/app.js`, `assets/style.css`) на GitHub Pages, данные в `data/*.json`,
> Python-агент в `agent/` (GitHub Actions по cron), уведомления в Telegram (`agent/common.py: send_telegram`).
> Интерфейс на русском, mobile-first, тёмная тема через CSS-переменные. Личные данные (оценки, черновики) хранятся только в localStorage —
> репозиторий публичный. Тесты: `python -m unittest discover tests`. После изменений проверить сайт локально (`start.bat`) на ширине 375px.

## 1. Статус заявки по каждой программе — сложность: низкая

> Добавь в трекер статус заявки для каждой программы: `idea` (изучаю) → `preparing` (готовлю) → `submitted` (подано) →
> `interview` (собеседование/экзамен) → `result` с исходом (`accepted` / `rejected` / `waitlist`) и полем заметки.
> Хранение: localStorage (`tracker.status`), так же как отметки чек-листа; при наличии GitHub-токена — опционально коммит через workflow
> `review.yml` (новое действие `status`, обработка в `agent/review.py`, поле `application_status` в programs.json).
> UI: бейдж статуса на карточке в списке, переключатель на странице программы, фильтр «Только активные» на главной.
> Программы со статусом `result` уходят вниз списка. Тест для `review.py status`. Готово, когда статус меняется в 1 тап и переживает перезагрузку.

## 2. Экспорт дедлайнов в календарь (.ics) — сложность: низкая

> Сгенерируй календарь `.ics` с дедлайнами всех программ. Два способа:
> (а) кнопка «Скачать в календарь» на сайте — формирует .ics в браузере (`Blob`, корректный `DTSTART` в UTC с учётом часового пояса дедлайна,
> `VALARM` за 7 и 1 день, в описании — статус confirmed/expected и ссылка на карточку);
> (б) агент при каждом запуске пишет `data/deadlines.ics`, чтобы на него можно было подписаться по URL GitHub Pages
> (Google Calendar → «Добавить по URL»). Программы без даты не включать; у expected-дат в названии пометка «(ожидается)».
> Добавь тест генерации .ics в Python и инструкцию подписки в README.

## 3. Даты экзаменов (ОРТ, IELTS, SAT, экзамены MEXT) — сложность: средняя

> Добавь сущность «события» (`data/events.json`): регистрация и даты ОРТ (testing.kg), даты IELTS в Бишкеке (British Council / IDP),
> даты SAT (College Board, международные даты), письменные экзамены MEXT в посольстве. Поля как у программ: date, time, timezone,
> status (confirmed/expected), source_url, quote, related_programs[]. Найди официальные даты на 2026/27 и заполни, у каждой — источник.
> Добавь официальные страницы в `data/sources.json` (kind=page, новое поле `event_id`), агент извлекает даты так же, с проверкой цитат.
> На главной — переключатель «Программы / Экзамены», напоминания в Telegram за 30/14/7/1 день до регистрации и до экзамена.

## 4. Еженедельная сводка в Telegram — сложность: низкая

> Добавь `agent/weekly_digest.py` и workflow `weekly-digest.yml` (понедельник 09:00 по Бишкеку, плюс ручной запуск с `--dry-run`).
> Сводка: 3–5 ближайших дедлайнов с днями до них и статусом, сколько пунктов чек-листа не готово по каждой из них, сколько изменений
> ждёт проверки в журнале, какие источники с ошибкой, были ли новые программы за неделю. Одно сообщение, HTML-разметка, ссылка на сайт.
> Чек-лист берётся из programs.json (локальные отметки агенту недоступны — указать это в README). Тест на формирование текста.

## 5. Эссе и мотивационные письма — сложность: средняя

> Добавь раздел «Эссе»: черновики, привязанные к программам, с требованиями из данных (`essays` в programs.json: тема/вопрос, лимит слов
> или страниц, язык, source_url). Заполни требования для программ, где они известны (AUCA statement of purpose до 700 слов,
> Stipendium Hungaricum мотивационное письмо от 1 стр. Times New Roman 12, Common App personal essay 650 слов и т.д. — только из официальных источников).
> Редактор: textarea с автосохранением в localStorage, счётчик слов и символов с подсветкой превышения, история версий (5 последних).
> Кнопка «Проверить в чате» отправляет черновик в чат (Gemini) с инструкцией дать отзыв по структуре и ясности, НЕ переписывать за автора.

## 6. Рекомендатели — сложность: низкая

> Добавь трекер рекомендаций: кто (имя, роль — учитель/директор), для каких программ, когда попросили, срок, статус
> (`asked` / `writing` / `received` / `submitted`), заметки. Хранение — localStorage (личные данные, репозиторий публичный).
> На карточке программы — блок «Рекомендации» с теми, кто к ней привязан; предупреждение, если до дедлайна < 14 дней, а рекомендация не получена.
> Экспорт/импорт JSON в настройках вместе с профилем.

## 7. Бюджет поступления — сложность: низкая

> Добавь раздел «Бюджет»: статьи расходов (сбор за подачу, IELTS/SAT/ОРТ, нотариальный перевод, медсправка, апостиль, фото, доставка документов),
> сумма, валюта (KGS/USD/EUR), к какой программе относится, срок оплаты, оплачено ли. Итоги по валютам и по программам, «нужно до конца месяца».
> Курсы не тянуть из интернета — поле для ручного курса в настройках. Хранение в localStorage. Известные официальные сборы (если есть) — в programs.json
> как `fees[]` с source_url, они подставляются шаблоном.

## 8. Бот отвечает на команды — сложность: средняя

> Сделай Telegram-бота интерактивным без платного сервера: Cloudflare Worker (бесплатный план) с webhook.
> Команды: `/deadlines` (ближайшие 5), `/todo` (неготовые документы из programs.json), `/program <id>` (кратко: дедлайн, статус, ссылки),
> `/pending` (что ждёт проверки), `/help`. Worker читает JSON с GitHub Pages, отвечает ТОЛЬКО chat id из белого списка (секрет в Worker).
> Код в `worker/` (wrangler.toml, index.js), инструкция деплоя в README (wrangler login, secrets, setWebhook). Без LLM в боте.

## 9. Работа без интернета (PWA) — сложность: низкая

> Сделай сайт устанавливаемым PWA с офлайн-режимом: service worker (`sw.js`) со стратегией network-first для `data/*.json`
> и cache-first для статики, версия кэша из константы; иконки 192/512 PNG в manifest; баннер «Данные из кэша от <дата>», когда сети нет.
> Учесть путь GitHub Pages (`/admission-tracker/`): scope и пути относительные. Проверить: загрузить, отключить сеть, перезагрузить — всё открывается.

## 10. Больше программ: вузы с полной финпомощью и обмены — сложность: высокая (ВЫПОЛНЕНО ПЕРВЫМ)

> Найди и добавь в `data/programs.json` программы бакалавриата, реально доступные гражданину Кыргызстана с полным или почти полным покрытием:
> вузы США, которые покрывают 100% доказанной потребности иностранцев (need-blind или need-aware), NYU Abu Dhabi, европейские варианты
> (бесплатное обучение + стипендии), программы обмена, если подходят по возрасту. Только официальные источники; у каждого факта — source_url
> и дословная цитата; неподтверждённое — null с пометкой. Для каждой: дедлайны цикла осень 2027 (EA/ED/RD), тесты (SAT/ACT, TOEFL/IELTS/Duolingo),
> финансовые формы (CSS Profile / ISFAA), документы. Страницы — в `data/sources.json`. Ничего не выдумывать.
